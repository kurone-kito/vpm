# Guidelines for AI Agents (Gemini CLI)

This file is the Gemini CLI entry point. Gemini CLI reads `GEMINI.md`
by default rather than `AGENTS.md`, so the full guidelines defined there
are imported below; treat the imported content as if it were written
directly in this file.

@AGENTS.md

This repository runs Issue-Driven Development (IDD); the imported
guidance's IDD workflow section is the operating default. Start from
[docs/idd-workflow.md](docs/idd-workflow.md), read
[docs/idd-policy.md](docs/idd-policy.md) for the recorded policy
decisions, and open
`.github/instructions/idd-overview-core.instructions.md` before claiming
IDD work.
